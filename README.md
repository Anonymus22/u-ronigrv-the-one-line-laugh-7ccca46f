A make.fun micro entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f): one original funny line, a single sentence of at most 200 characters. `main.ts` (Node 22, standard library only, fully deterministic) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

## The line

> Every morning my five alarms hold a vote on whether I get up, and I lose five to one every single time.

(103 characters, one sentence.)

## Run

```sh
node main.ts
# writes entry.txt to /output by default, or to $MAKEFUN_OUTPUT_DIR when set
```
